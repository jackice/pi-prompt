# 统一输入区排版设计

以 Pi 1.6.0 全屏模式为约束。`band` 和 `borderless` 从上到下统一为提示行、状态带、输入。输入下方不留固定空行；补全按需在输入之后展开。`shape: native` 明确交还 Pi 原生编辑器，不套用扩展排版。

- 提示行：运行、重试、压缩等复用 Pi 提供的指示器；有会话标题时显示标题。空闲时无标题用当前目录，填满 Pi 固定保留的三行，不制造提示或读取私有状态。
- 状态带：沿用 `segments`、上下文 gauge 和窄屏折叠；`none` 模式把 `metaSegments` 并入状态带。`detailSegments` 仅在需要独立一行时配置，有可显示的数据才插在输入上方，避免重复字段。
- `footerMode: native` 默认不接管 footer，原生底栏紧接单行输入；`none` 安装零行 footer，输入成为最底行。两个值不改变原生编辑、补全或按键。
- 删除 `inline`、`compact`、`replace`、`hidden` 执行分支。旧值明确报告迁移方法，不能静默回退；发布前记录迁移配置并用已发布包迁移本机。版本 `0.2.0` 标明配置不兼容。
